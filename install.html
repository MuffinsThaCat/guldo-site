Install

Install the command-line tool

One command, guldo, lets you try a solver on your own computer, submit it to a round, and check any certificate yourself. No account, no browser.

Honest status. This package was built and tried on the author's own computer: it was installed once (with pip; pipx itself has not been tried) and used to check one real certificate. It is not on the public Python package index, and it has not been installed on a clean computer by anyone else. Exact step counting and the extra claims pass their own tests. A counted test round has run end to end on the project's server and a first real round is open, but no outside participant has used any of it yet.

Three steps

1

Download

guldo-0.1.0.zip (345 KB). To check what you got, compare its SHA-256 with this one:

2bc07d657cd1990fc121459b53cf5a55aababf2d6b1444e8f2bcca8bb13c7d47

shasum -a 256 guldo-0.1.0.zip

On Linux the command is sha256sum.

2

Install

The easy way is pipx, which keeps the tool in its own private folder:

pipx install ./guldo-0.1.0.zip

Or use a virtual environment:

python3 -m venv ~/.guldo-venv && ~/.guldo-venv/bin/pip install ./guldo-0.1.0.zip
3

Check it works

You should see a version number and a list of the other tools:

guldo --version
guldo tools

With a virtual environment, run ~/.guldo-venv/bin/guldo instead.

What you need

  • A Mac or a Linux computer. Windows is not supported.
  • Python 3.9 or newer. Exact step counting needs Python 3.12 or newer.
  • The numerical library numpy, which is installed for you.
  • Optional: pip install "./guldo-0.1.0.zip[attest]" in a virtual environment adds signed attestations; [lattice] adds the library the lattice problems use.

Try it

  • Check a solver before you submit: guldo lint my_solver.py --family factor
  • See what a practice run on three secret numbers of your own would cost: guldo practice my_solver.py --family factor --count --dims 38 40 42. It only prints the plan; add --yes to run it, which can take hours.
  • Check a certificate someone gave you: guldo verify their.cert.json
  • Work out a benchmark score from it: guldo claims correctness their.cert.json
  • See a round and submit: guldo rounds --server URL

Good to know

  • Checking is safe, re-running is not. guldo verify FILE never runs any code from the certificate. Adding --rerun all --execute re-runs the solvers inside it on your machine, with no protection: do that only on a throwaway computer or virtual machine.
  • Your receipts and tokens are kept in ~/.svp, readable only by you. A submission token is shown once; keep it.
  • Some commands write under the tool's own folder, which is why pipx or a virtual environment is the right way to install it. A problem you compile yourself is saved there too, and an upgrade would replace it: keep your own problem declarations in a copy of the repository.
  • To update, install the newer file over the old one: pipx install --force ./new-file.zip. To remove it: pipx uninstall guldo.
  • Prefer to build it yourself? In a checkout of the repository, make package creates the same folder, and the hash of this download changes with every build of this site, so always compare against the hash shown above.
