# guldo-site

The built static website for Guldo (guldo.org): verifiable speedup claims.

This repository holds only the generated site. It is built from the main project with `make site` and copied here; do not edit these files by hand.
The Install page's download (`downloads/guldo-0.1.0.zip`) is built in the same step, and its SHA-256 is shown on the page.
